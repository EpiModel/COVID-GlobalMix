# COVID-GlobalMix

## Introduction
This is a repository for the network modeling for COVID-GlobalMix

## Table of content
Below is a list of all the scripts and their descriptions.

- **1-network_params.R**: Calculation of individual-level summary statistics
- **2-network_targetstats.R**: Calculation of target statistics
- **3-network_est.R**: Estimation of models
- **4-network_dx.R**: Diagnosis of models
- **5-network_sim.R**: Simulate home, school, work, and nonhome layers for the rural and urban networks
